Navet Provider Lab

Private virtual devices, scene Flow cards, notifications, and live climate samples for testing
Navet's Homey provider. Install the devices, flows, moods, zones, and favorites with
pnpm provider-lab:homey from the Navet repository. See testing/provider-lab/README.md for the
permission coverage checklist.

This app is intended only for local development and must not be published to the Homey App Store.
