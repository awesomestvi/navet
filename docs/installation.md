First, choose the smart-home system you already use.

## I use Home Assistant

Open the [Home Assistant installation guide](/install/home-assistant/).

The guide gives you three choices:

1. **HACS custom panel** if you already use HACS.
2. **Home Assistant App** if you use Home Assistant OS and want Home Assistant to run Navet.
3. **Standalone Docker** if you already manage Docker yourself.

## I use Homey

Open the [Homey installation guide](/install/homey/).

## I use openHAB

Open the [openHAB installation guide](/install/openhab/).

## I want a development build

Use [Navet Dev](/install/navet-dev/) only when you want to test unfinished changes. Development
builds can break more often than the normal release.

## After installation

Follow [Your first 15 minutes](/guide/quick-start/first-15-minutes/) to complete setup and add your first card.
