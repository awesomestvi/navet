## Start with the installation guide

Recheck the guide for your active provider and deployment route. Authentication, URLs, and update
behavior differ between the custom panel, add-on, and standalone applications.

## Before reporting a problem

1. Record the Navet version and deployment route.
2. Confirm the provider itself is reachable.
3. Capture the exact error and the action that triggered it.
4. Remove tokens, private URLs, entity names, and household details from logs or screenshots.
5. Search existing [GitHub issues](https://github.com/awesomestvi/navet/issues).

If the problem is new, open an issue with the smallest reproducible description you can provide.

## Security

Do not expose Navet or your provider directly to the public internet without a deliberate security
boundary. Read the full [security policy](/security/) before configuring remote access.
